FAQ

Questions, answered.

Is Zyro really free?
Yes. Free to use with a daily limit that refills every day. No credit card, no trial timer. Create an account only if you want to sync chats across devices.
Do I need to create an account?
No. You can start chatting immediately and your chats stay on your device. If you want to sync chats across devices, create a free account — it takes about 20 seconds.
What can I attach to a message?
Up to 3 files or images per message. Files can be PDFs, code files, or text files up to 8 MB each. Images can be JPG, PNG, or WebP and get shrunk automatically before sending.
What's the difference between Fast, Auto, and Thinking?
Fast gives short, quick answers — great for simple questions. Auto balances speed and depth for everyday use. Thinking takes longer and reasons through the problem step by step — best for hard math, tricky code, and complex topics.
What are the study modes?
Four modes, chosen with the dropdown next to the mode picker. Chat is normal conversation. Solver walks through problems step by step with formulas. Socratic guides you with questions instead of just giving the answer. Exam prep quizzes you one question at a time and tracks your score.
Can Zyro run code?
Yes — Python and JavaScript code blocks have a Run button that executes them safely in your browser and shows the output. Python takes a few seconds the first time (one-time download).
Does Zyro make mistakes?
Yes — any AI can. Always check important code, facts, formulas, and numbers before relying on them. Zyro is a tool to help you, not a replacement for thinking.
